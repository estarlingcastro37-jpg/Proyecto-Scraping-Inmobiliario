# Proyecto de Scraping Inmobiliario

Proyecto académico de web scraping en Python para recopilar y analizar información de propiedades inmobiliarias en República Dominicana de **Corotos, SuperCasas y Plusval**.

## Objetivo
Extraer hasta 200 propiedades de cada fuente y consolidar los datos de nombre, precio, ubicación, vendedor, tamaño, habitaciones, baños y parqueos. Generar resultados en Excel y Parquet, un reporte HTML con `ydata-profiling` y un archivo JSON con el estado del scraping.

## Tecnologías
Python, Requests, BeautifulSoup, Pandas y ydata-profiling. El código principal se desarrolló en Google Colab (`.ipynb`).
